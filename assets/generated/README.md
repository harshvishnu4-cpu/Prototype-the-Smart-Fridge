# Generated asset library

These files were generated separately from the supplied storyboard. The storyboard was used as a visual and narrative reference, not as an instruction document.

All interface labels, questions, buttons, and feedback remain live HTML. No UI text is baked into these images.

## Prompt set

The built-in ImageGen workflow was used. Prompts followed one shared art direction: polished, soft 3D animated educational-game artwork for Grade 6; warm optimistic lighting; purple, blue, teal, cream, amber, and orange accents; original characters and unbranded props; no embedded text, logos, watermarks, or UI. Each character pose used `meera-presenting.png` as the identity anchor. Environment variants used the closed-kitchen image as their scene anchor, and classroom outcome variants used the balanced cupboard image as their composition anchor.
