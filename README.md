# Smart Fridge Mission

A short learning game: help Meera teach her family's smart fridge when to order milk, so it never runs out and nothing goes to waste.

## How to launch

Open `index.html` in a web browser (double-click it). No installation, build step or server is needed.

Recommended: a current version of Chrome or Edge. Firefox and Safari also work. The game is designed for landscape screens and scales to fit any window size.

## Offline

Everything the game needs (code, libraries, fonts, images and sounds) is inside this folder, so it runs without an internet connection. Keep the folder structure intact when copying or sharing it.

Meera's voice-over is pre-recorded and stored in `assets/audio/vo/`. Each step's line plays automatically; "Replay Narration" in the sound menu plays it again, and "Mute All Sounds" silences everything.

## Controls

- Mouse or touch: tap cards and buttons.
- `Tab` / `Enter` / `Space`: keyboard navigation.
- `1` `2` `3`: choose an answer card.
- `Esc`: pause.
